# AuthZEN Cedar Policy Store Format (Draft)

Working draft for the [OpenID AuthZEN](https://openid.net/wg/authzen/) Working Group, derived from [Cedar RFC 0101](https://github.com/ossdhaval/cedar-rfcs/blob/main/text/0101-policy-store-specification.md).

## Files

| File | Role |
|------|------|
| `draft-schwartz-authzen-policy-store.md` | Source (kramdown-rfc2629 / RFC XML) |
| `draft-schwartz-authzen-policy-store.xml` | Generated RFC XML |
| `draft-schwartz-authzen-policy-store.html` | Published HTML output |

## Build

```sh
./build.sh
```

Requires Ruby with `kramdown-rfc2629` and Python 3 with `xml2rfc` (created in `.venv` on first run).

## Status

Internet-draft style specification; not yet submitted to the AuthZEN WG. Update author contact addresses in the markdown front matter before publication.
